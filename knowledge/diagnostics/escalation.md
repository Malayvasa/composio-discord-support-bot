# Escalation

Escalate when:

- Production has 5xxs or elevated error rate.
- Multiple customers report the same failure.
- Auth is broken for a managed toolkit.
- Billing, security, data integrity, or privacy is involved.
- The customer is blocked and diagnostics show an internal failure.

Create a ticket or handoff message with:

- Clear title.
- Customer impact.
- Reproduction steps.
- Evidence bundle.
- Links to Discord context, logs, traces, dashboards, or tickets.
- Suggested owner or service.

If the issue is likely customer-side configuration, provide the fix and note what evidence supports that conclusion.
